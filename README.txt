# Python Data Analysis Notes

A collection of Python notebooks covering NumPy, Pandas, Matplotlib, Plotly, data cleaning, aggregation, and exploratory data analysis.

## Topics Covered

- NumPy fundamentals
- Pandas Series and DataFrames
- Data cleaning and missing values
- GroupBy and aggregation
- Matplotlib visualisation
- Plotly interactive visualisation
- E-commerce sales analysis case study
